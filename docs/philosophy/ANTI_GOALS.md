# Anti Goals

## SceneForge is NOT...

### An LLM wrapper

Providers are replaceable.

Understanding is permanent.

---

### A comic generator

Comic generation is one application.

Not the framework.

---

### A collection of scripts

Every capability must integrate into a coherent architecture.

---

### A model benchmark

SceneForge measures understanding, not model popularity.

---

### A workflow tied to one vendor

Every cloud provider can disappear tomorrow.

The framework must continue to work.

---

### A monolith

Everything should be replaceable through plugins.
