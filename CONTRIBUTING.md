# Contributing

Thank you for your interest in SceneForge.

## Philosophy

We value:

- clean architecture
- readable code
- documentation
- reproducibility
- benchmarking

over clever shortcuts.

## Before writing code

Please read:

- README.md
- docs/
- .ai/START_HERE.md

## Pull Requests

Every PR should:

- include tests when applicable
- update documentation
- avoid breaking architecture
- follow coding guidelines

## Questions

Discussions are encouraged before implementing large features.
