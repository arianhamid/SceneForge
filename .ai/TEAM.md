# SceneForge Team Philosophy

SceneForge is built through collaboration between human creativity and AI-assisted engineering.

## Human Responsibilities

- Define the vision.
- Make architectural decisions.
- Validate assumptions.
- Test the framework.
- Review every contribution.
- Keep the project aligned with its mission.

## AI Responsibilities

- Accelerate implementation.
- Propose architectures.
- Write documentation.
- Generate boilerplate.
- Review code.
- Suggest improvements.
- Explain complex concepts.

## Shared Principles

- Build for the long term.
- Prefer clarity over cleverness.
- Keep the architecture simple.
- Write code that teaches.
- Leave the project better than you found it.

## Our Goal

Create an open framework that enables anyone to understand stories through reusable knowledge.

Every contributor—human or AI—is expected to improve the framework while respecting its architecture and philosophy.
