# North Star

> Every architectural decision should move SceneForge closer to this vision.

---

# Our Mission

SceneForge exists to transform videos into reusable knowledge.

The framework should understand stories with increasing depth while remaining independent of any specific AI model or provider.

---

# The North Star

A user should be able to analyze any movie once and reuse that understanding forever.

Applications should consume structured understanding rather than raw AI outputs.

---

# What Success Looks Like

A single movie analysis can power:

- Comic generation
- Storyboards
- Novels
- Search engines
- Video question answering
- Character databases
- Timeline visualization
- Knowledge graphs
- Educational tools
- AI agents
- Future applications we have not imagined yet

without running the expensive analysis pipeline again.

---

# Long-Term Objectives

## Understand

Extract reliable facts from visual stories.

---

## Organize

Represent knowledge in a structured, reusable form.

---

## Reason

Infer relationships, intentions, themes, and narrative structure.

---

## Reuse

Allow many applications to consume the same understanding.

---

## Extend

Make every capability replaceable through plugins.

---

# Design Compass

Whenever a new feature is proposed, ask:

1. Does this increase reusable understanding?
2. Is it model agnostic?
3. Can another application benefit from it?
4. Does it belong in the framework instead of an application?
5. Will this design still make sense in five years?

If the answer to most of these questions is "no", reconsider the design.

---

# Our Guiding Belief

Models will evolve.

Providers will change.

Hardware will improve.

SceneForge should remain valuable because it is built around knowledge rather than models.
