# Core Principles

Every contribution to SceneForge should reinforce these principles.

---

## 1. Architecture before implementation

Code follows architecture.

Never the opposite.

---

## 2. Knowledge before generation

Knowledge is reusable.

Generation is temporary.

---

## 3. Capabilities before models

Framework APIs expose capabilities.

Never model names.

---

## 4. Immutable artifacts

Artifacts are facts.

Facts never change.

---

## 5. Plugins over coupling

Everything replaceable.

Nothing hardcoded.

---

## 6. One source of truth

Knowledge should exist exactly once.

Applications consume it.

They never recreate it.

---

## 7. Documentation is part of the product

A feature without documentation
is an incomplete feature.

---

## 8. Every component should be testable

Every abstraction
must support automated testing.

---

## 9. Local-first

Cloud providers are optional.

Local execution should always be possible.

---

## 10. Think in decades

Optimize for maintainability.

Not today's trends.
